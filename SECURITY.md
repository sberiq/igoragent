# Security Policy

## Supported versions

Only the latest `main` branch is supported during the initial development phase.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities involving authentication, Telegram sessions, credentials, sensitive memory, remote access or account actions.

Report privately to the repository owner with:

- a concise description and impact;
- affected commit/version;
- steps to reproduce;
- a proof of concept that does not access data or accounts you do not own.

Do not include API keys, Telegram login codes, session files, passwords, seed phrases or private user content. The owner should acknowledge the report, assess the issue and coordinate a remediation timeline before disclosure.
